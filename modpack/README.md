# Skybound fork (modpack)

A trimmed fork of **Create Aeronautics - Skybound** v17.1.0 (NeoForge 21.1, Minecraft 1.21.1) plus the mods built in this repo.

## Files

| File | What it is |
|---|---|
| `mods-audit.json` | every mod of the original pack: group, recommendation, dependency ids |
| `decisions.json` | the keep/scrap choices, exported from the audit checklist (overrides the recommendation) |
| `extra-mods.json` | mods added on top of the original pack (CurseForge project + file ids) |
| `build_pack.py` | builds the pack: `python modpack/build_pack.py` |
| `sync_server.py` | deletes scrapped jars on the UltraServers mods folder and uploads our jars over SFTP (NOT to be run until the server is backed up and friends are told) |
| `check_deps.py` | verifies the kept set against the dependencies the jars themselves declare; finds stray jars |
| `migrate_server.py` | migrates a server folder (snapshot or live files) to the trimmed set, with a backup; dry run by default |
| `boot_server.py` | installs a local headless NeoForge server, syncs the pack into it, boots it and summarizes the log |
| `release.py` | local release: Gradle build of every mod, pack rebuild, everything collected into `dist/<version>/` (no CI, ever) |
| `make_grid.py` / `checklist-grid.json` / `checklist-upgrades.json` / `upgrades.md` | the Checklist mod's grid and upgrade catalog |
| `audit.html` | the interactive checklist (published as a Claude artifact; its saved choices feed `decisions.json`) |
| `out/` | build output, not committed |

## Build the pack

```bash
python modpack/build_pack.py
```

Reads the original pack from the local CurseForge instance, applies `decisions.json`, auto-resolves libraries
(a library stays only if something kept still needs it), adds `extra-mods.json`, and bundles any jars found in
`*/build/libs/` (our own mods) under `overrides/mods`. Output in `modpack/out/`:

- `radarcraft-<version>.zip`: import it in the CurseForge app (Create Custom Profile, Import).
- `report.md`: everything kept and scrapped, with reasons.
- `server-remove.txt` / `server-add.txt`: jar names to delete from / add to the server.

Run `gradlew build` first if you want the latest versions of our own mods inside the zip.

## Update the server

1. `pip install paramiko`, copy `server.example.json` to `server.json`, fill in the SFTP details from the UltraServers panel.
2. `$env:ULTRASERVERS_SFTP_PASSWORD = "..."` in the shell (never commit it).
3. `python modpack/sync_server.py plan` to see what would change, then `python modpack/sync_server.py apply --yes`.
4. Also upload the pack's `overrides/config` and `overrides/kubejs` if they changed, then restart the server from the panel.

## Boot test (2026-10-26)

A local headless NeoForge 21.1.248 server (`boot_server.py`, folder `testserver/`, not committed) was booted twice:
with the trimmed set (343 server-side jars) and with the original pack's full server-side set (368 jars). Both reach
"Done" in about two minutes and log the same 43 unique errors, all pre-existing in the original pack: broken loot
tables in Beautify and Create: Enchantment Industry, a few bad recipes (Just Enough Breeding, Ender's Delight),
KubeJS tags referencing absent mods, a Sable physics entry, a Without Structures mixin. The trimmed pack adds no
new error. Client-only mods (listed in `client-only-mods.txt`) must not be on a dedicated server: Sodium and Punchy
crash it at startup, which is also why the live server's mods folder differs from the client's.

### Migration rehearsal

The same test server was then given the ORIGINAL mod set and a world generated by it, and `migrate_server.py --apply`
was run on that folder (28 scrapped jars deleted, our 3 server-side jars and the Checklist configs added, backup made).
Booting on the old world: started in 169 s, no crash. NeoForge logs the 28 removed mods as "MISSING" and continues.
Every chunk section that held a block from a removed mod logs one recoverable error and replaces it with air: in this
world that was 155 sections, all Modern Industrialization / Powah ores (`scan_world.py` counts them beforehand).
Expect the same on the live world: ore veins from those two mods become small air pockets in already-generated
chunks, and placed machines / cables / Tom's storage blocks / Security Craft blocks vanish. New chunks are unaffected.
Player data from Pufferfish Skills (skill points, bought hearts) is simply ignored; Checklist starts everyone at
level 0 with whatever they have actually achieved.

### Loot / spawn tuning (`config-patches.json`)

Applied on every pack build: goblin traders about 10x rarer (spawn chance 25 -> 5 per attempt, attempts every
24000 ticks instead of 12000); Loot Integrations' extra weight for modded items in chests 3 -> 1 (the single biggest
reason modded loot was everywhere); Artifacts 2x rarer in chests, archaeology and on mobs; Simply Swords loot weights
halved with pity thresholds doubled. Mods with their own self-contained loot tables (Bumblezone, Aether, Eternal
Starlight dungeons) are untouched; say so if those still feel too generous and a small global loot modifier mod can
halve modded drops everywhere.

## Decisions so far

Review outcome: 426 mods audited, 384 kept. Scrapped: the non-Create tech stack (Modern Industrialization, Modern Dynamics,
Powah, Flux Networks, Wireless Chargers, Charging Gadgets, Cognition, Security Craft, Additional Enchanted Miner), duplicate
accessory and storage systems (Accessories, Tom's Simple Storage, Nether Chested, Super Ore Block), pack branding
(BisectHosting menu, loading tips, toasts, AutoMessage, StartInv, Immersive UI, Underlay, Modern World Creation, Loading
Backgrounds), Exclusive Weapons, Farmers Structures, Punchy (its item-swap flip animation), and four libraries nothing needed.
Added: Inventory Crafting Grid (3x3 crafting in the inventory). The pack's KubeJS scripts and FTB quests reference only
Create-family mods, so none of the removals break them.

Resource packs from the original (the "Realistic 3D" packs) are dropped; the three shader packs stay.
